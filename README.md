Student Management System

Project Description

A simple Student Management System built using Python.

The program allows users to enter student information and display it.

Features

Enter student name.

Enter student ID.

Enter department.

Enter GPA.

Display student information.

Show a confirmation message after adding a student.

Technologies Used

Python

Git

GitHub

Visual Studio Code

How to Run

Install Python.

Open the project folder in VS Code.

Open the terminal.

Run the following command:

python main.py
